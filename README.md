# 科技大學-跨域技職實務模組資源地圖 (TechUni)
### Operational Module OS · 技專校院跨域實務專題與產學資源拓撲圖譜

本專案為科技大學與技專校院推動跨領域技職實務學程、雙師協同、在地實務專題與產學就業對接之**資源模組地圖與策略拓撲視覺化系統**。  
前端採用純靜態 Single Page Web App (SPA)，整合 **React 18**、**D3.js 力導向圖形引擎** 與 **Tailwind CSS**，直接透過 **GitHub Pages** 提供永久穩定且免更換網址的線上展示服務；同時直接串接 **Google 試算表** 進行即時數據同步與自動去識別化處理。

### 步驟 1：利用成果報告（至少三年）與 AI 產生節點並判定學校位階

單純憑人工手動整理三年份的厚重成果報告往往費時且容易遺漏。**建議使用具備長文本解析能力的 AI 工具（如 Gemini 1.5 Pro / Advanced 或 ChatGPT Plus）**，搭配我們設計的【專用結構化提示詞（Prompt）】，由 AI 一鍵完成**「資料萃取」**、**「節點比重評定」**與**「該校當前成熟度位階精準判定」**。

#### 💡 科技大學成熟度位階判定標準（本系統定位模型）：
AI 將依據節點分佈與比重加權，客觀判定貴校當前所處的策略發展位階：
* **階梯一（技職架構奠基期 · Phase 1 主導）**：節點多集中於跨系學程規章審核、工場職安衛安檢與基礎開課，尚未具備百萬級實作基地或專題競賽成果。
* **階梯二（雙師產學深化期 · Phase 2 主導）**：百萬級智慧實作工場到位、金牌業界大師入校共時授課、全學期校外企業實習成形，正往在地實務專題跨越。
* **階梯三（在地實務深耕期 · Phase 3 主導）**：具備扎實的地方創生實務專題、傳統工藝數位化與智慧製造轉譯，並建立完備的知情同意與智財共有機制。
* **階梯四（成熟典範輸出期 · Phase 4 主導）**：國家乙級技術士考照通過率高、全國技專實務專題競賽獲大獎、新型/發明專利成功商轉，並透過校務 IR 數據精準追蹤畢業生起薪與就業競爭力。

#### 📋 複製給 Gemini / ChatGPT 的專用提示詞範本（Prompt Template）

> 💡 **快速取得方式**：
> - 📄 **[點此直接開啟 / 下載完整提示詞檔案 (prompt.txt)](prompt.txt)**（推薦！純文字檔一鍵複製，避免格式跑掉）

````markdown
你是一位高等教育科技大學技專校院跨領域實務學程與產學資源拓撲分析專家。
請閱讀我所提供的【本校過去至少三年的成果報告／期末結案報告】資料，完成以下兩項任務：

### 【任務一：精確判定本校當前發展階段與 SWOT 策略診斷】
請依據三年報告累積的實質成效，對標以下成熟度階梯與 SWOT 策略架構，給出客觀白話的診斷報告：
1. 階段落點判定：明確指認本校目前主要位處於哪一個階段？（階梯一：技職架構奠基期 / 階梯二：雙師產學深化期 / 階梯三：在地實務深耕期 / 階梯四：成熟典範輸出期），是否有跨階段推進的趨勢？
2. SWOT 結構性診斷：
   - 🌟 優勢 (S)：本校高權重（比重 4~5）核心資產主要集中在何處？最難被取代的技職實作護城河是什麼？
   - ⚠️ 劣勢 (W)：耗材採購與例行庶務比重是否過高？哪一個階段存在斷鏈或瓶頸痛點？
   - 🚀 機會 (O)：可對接哪些部會政策紅利（教育部高教深耕、技專校院產業菁英實作基地、USR）或智慧製造、地方創生與企業高薪預聘商機？
   - 🛡️ 威脅 (T)：面臨哪些少子化技職生源挑戰、實作工場工安法規、產學智財共有或設備維護費用風險？
3. 下一步推進行動建議：依據 SWOT 交叉比對，提出 2~3 項具體可行的突破方針（如 SO/WO/ST/WT 策略方向）。

---

### 【任務二：萃取 35~50 筆拓撲節點資料（以 Markdown 表格輸出）】
請從三年成果報告中，精準提取 35~50 個核心項目，嚴格依照以下 5 欄規格輸出：
1. 關鍵詞 (ID)：具體項目名稱（10字以內），禁止空泛詞彙，如「百萬智慧實作基地」、「傳統工藝逆向數位建模」。
2. 所屬分類 (Group)：必須且只能從以下標籤中擇一歸類：
   - 對應 PHASE 01（建立技職學程架構）：[行政授權]、[行政瑣務]、[實作認證]
   - 對應 PHASE 02（雙師協同與產學共構）：[核心主軸]、[技術指標]、[雙師協同]、[產學對接]、[基地實作]
   - 對應 PHASE 03（實務專題在地轉譯）：[實務專題]、[在地創生]、[文化轉譯]、[工藝數位]、[技術移轉]
   - 對應 PHASE 04（技職典範與職涯對接）：[證照專利]、[競賽成果]、[職涯對接]、[績效指標]、[典範輸出]
3. 比重 (Importance)：數值 1 ~ 5，請嚴格按照以下標準給分，且必須呈現金字塔階梯分佈（比重 5 不得超過總數的 15%，比重 1~2 應佔 40% 以上）：
   - 比重 1（基礎維持成本）：例行公文、耗材報銷、機台定期清潔校正等日常剛性維持作業。
   - 比重 2（基礎動員福利）：學生工讀助學金、跨系宣傳說明會、學程品牌 Logo 等基礎誘因。
   - 比重 3（結構資本協同）：跨系微學程開課、產官學專家委員會、物聯網技術講座等制度合作。
   - 比重 4（實體核心專業）：百萬智慧實作基地、機台操作檢核認證、全學期校外實習、技術作品集等高階實作。
   - 比重 5（頂層策略優勢）：金牌業師雙師共時、國家乙級考照通過、全國技專專題競賽獲獎、專利商轉技轉、校務 IR 薪資數據追蹤等核心資產。
4. 特性說明：一句話精要說明該項目的核心價值與執行內容（30~50字）。
5. 鏈結關係建議 (Links)：列出 1~3 個有實質合作或連鎖關係的「其他節點名稱」，以半形逗號分隔。（注意：此處提及的名稱必須同時出現在本次表格的 A 欄 ID 中，嚴禁出現幽靈節點）。

請先輸出【任務一：本校當前發展位階判定報告】，接著輸出【任務二：資料表格】。
````

#### 💡 提示詞設計避坑清單（本 Prompt 為何如此設計？）：
* **避免節點全部打 5 分**：強制約束「比重 5 不得超過 15%」，確保視覺化圖譜有大小層次，凸顯真正的技職核心戰略焦點。
* **避免圖譜連線斷裂（幽靈節點）**：強制約束「Links 內的名稱必須嚴格存在於清單中」，確保 D3 繪圖引擎能完美繪出完整的關聯網絡。
* **避免過於空泛或數量過少**：要求鎖定 35~50 筆節點，確保圖譜物理引力平衡且資訊厚度充足。

### 步驟 2：利用本 GitHub 生成分支（Fork）做出自己的拓樸

不需要重寫任何前端程式碼或 D3 視覺化邏輯，只需透過 GitHub 分支複製即可快速上線：

1. **生成分支／副本（Fork 儲存庫）**：
   - 在本專案右上角點擊 **Fork**（生成分支）。
   - 選擇您的個人帳號或學校組織，點擊 **Create fork**。
2. **替換試算表 ID**：
   - 在您 Fork 的儲存庫中，點選開啟 `index.html`。
   - 點擊右上角鉛筆圖示（Edit this file）進行編輯。
   - 找到 `sheetCsvUrl` 這一行，將試算表 ID 替換成步驟 1 取得的專屬 ID：
     ```javascript
     // 替換為您的專屬 Google 試算表 ID
     const sheetCsvUrl = 'https://docs.google.com/spreadsheets/d/【您的試算表ID】/gviz/tq?tqx=out:csv';
     ```
   - （可選）您也可以在此檔案搜尋並修改網頁標題或自訂文字。
   - 點擊右上角 **Commit changes** 儲存變更。
3. **啟用 GitHub Pages 上線**：
   - 進入儲存庫頂部的 **Settings** ➜ 左側 **Pages**。
   - 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，資料夾保持 `/ (root)`，點擊 **Save**。
   - 等候約 1~2 分鐘，即可獲得您專屬的公開拓樸地圖網址（例如：`https://<您的帳號>.github.io/TechUni/`）！

## 🎯 使用與操作指南

### 1. 圖譜視覺化操作
- **畫布縮放**：使用滑鼠滾輪或觸控板手勢放大／縮小圖譜。
- **畫布拖曳**：在空白處按住滑鼠左鍵拖曳，可平移視角。
- **節點探索**：將滑鼠移至節點上並點擊，左下方會彈出「節點詳情卡片」，顯示該節點的權重等級、詳細說明與所屬分類。
- **節點自訂位置**：按住任一節點可拖動改變排列，釋放後彈簧物理引擎會自動重新平衡。

### 2. 側邊欄策略推進導覽
- **展開階段詳情**：點擊左側 PHASE 01 ~ 04 手風琴面板，即可查看各階段之「關鍵執行步驟」與「VRIO 策略核心建議」。
- **快速聚焦節點**：在展開的面板中點選「核心關聯節點」標籤，地圖會立即自動飛入對焦該節點。
- **收合側邊欄**：點擊粉紅色浮動箭頭按鈕，可將左側選單收起，享受全螢幕圖譜視野。

### 3. 📄 一鍵產生完整策略診斷報告（全面整合 SWOT 分析與 Word 匯出）
- **痛點解決**：若校內主管或同仁對動態拓撲地圖較不熟悉，可點擊左側側邊欄頂部的 **「完整策略報告與 SWOT / 下載 Word」** 按鈕。
- **全自動 SWOT 診斷**：系統引擎會自動分析現有節點與比重配置，深入淺出地產出：
  1. **當前成熟度落點判定**：白話指認貴校目前所處的發展位階與推進狀態（附四大階段數據分佈表）。
  2. **SWOT 綜合分析矩陣（2x2 矩陣速覽）**：
     - **🌟 S (內部優勢)**：盤點比重 4~5 之旗艦核心資產（智慧實作工場、雙師共時、專利商轉），明確指出不可輕易被複製的護城河。
     - **⚠️ W (內部劣勢)**：客觀檢驗耗材採購與例行庶務成本比重、成果產出斷裂點與跨階段鏈結瓶頸。
     - **🚀 O (外部機會)**：結合教育部高教深耕、產業實作基地政策紅利、智慧製造與企業高薪預聘趨勢。
     - **🛡️ T (外部威脅)**：超前預警少子化技職生源競爭、工場工安衛生法規與高階設備折舊維護風險。
  3. **SWOT 四大構面深度剖析**：提供白話條例式解析，包含核心資產清單、特性說明與短板警訊。
  4. **SWOT 交叉策略矩陣與突破行動方針**：
     - **🟢 SO 策略（增長突破型）**：發揮優勢 · 把握機會
     - **🔵 WO 策略（翻轉改善型）**：克服劣勢 · 把握機會
     - **🟠 ST 策略（避險多元型）**：發揮優勢 · 化解威脅
     - **🔴 WT 策略（精實防禦型）**：精實劣勢 · 迴避威脅
- **多管道匯出**：視窗內支援線上直接閱讀、**一鍵下載標準 Word 報告 (.doc)**，或使用 **列印 / 另存為 PDF** 供校務主管會議、自評報告與專案計畫撰寫直接引用。

## 🌟 系統特色與架構

1. **D3.js 物理力學互動拓撲**：
   - 節點具備彈性引力與防碰撞機制，支援滑鼠拖曳、滾輪平滑縮放與畫布任意平移。
   - 依節點策略比重（Importance 1 ~ 5）動態調整節點半徑與視覺光暈，重點樞紐一目了然。
2. **四大策略推進階段（Phase）立體架構**：
   - **PHASE 01: 建立技職學程架構**（藍）：跨系學程規章、工場職安安檢、選課通道與品牌識別。
   - **PHASE 02: 雙師協同與產學共構**（綠）：金牌業師共時授課、百萬智慧工場、全學期校外企業實習。
   - **PHASE 03: 實務專題在地轉譯**（粉）：地方創生實務專題、傳統工藝逆向數位建模、智財共有與場域協作。
   - **PHASE 04: 技職典範與職涯對接**（橘）：國家乙級考照、全國專題競賽獲獎、新型專利商轉與校務 IR 薪資追蹤。
3. **策略側邊欄與視角飛入對焦**：
   - 左側磨砂手風琴卡片提供各階段「關鍵執行步驟」與「VRIO 策略核心建議」。
   - 點擊階段或關聯節點標籤時，畫布相機會**自動平滑飛入放大對焦**該核心區域。
4. **雲端試算表零延遲同步**：
   - 前端透過 Google Visualization API (gviz/tq) 支援 CORS 直接拉取試算表 CSV。
   - 後台試算表更新後，前台網頁重整即刻自動生效，毋需重新建置或重新部署。
5. **資料安全與動態去識別化**：
   - 內建一對一即時去識別化過濾（校名替換為示範科技大學、單位代稱轉譯、隱匿機敏年份）。
   - 具備離線防護機制：若試算表離線或網路中斷，自動切換至內建 45 筆結構化備用數據確保系統永不中斷。
